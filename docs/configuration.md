# 配置与评分

**简体中文** · [English](configuration.en.md)

配置文件采用 JSON，当前 `schemaVersion` 为 `1`。建议通过编辑器创建配置，不要把浏览器的答题缓存当作项目配置导入。

## 顶层字段

| 字段            | 含义                                         |
| --------------- | -------------------------------------------- |
| `schemaVersion` | 配置结构版本；未知版本会阻止导入             |
| `id`            | 项目编号，隔离本地草稿；从模板新建时自动生成 |
| `site`          | 页面名称、文案和主题颜色                     |
| `settings`      | 量表、分页、抽题与编辑入口                   |
| `dimensions`    | 有顺序的双极维度列表                         |
| `questions`     | 题库，最多 500 题                            |
| `profiles`      | 可选的专属结果组合，最多 1024 条             |
| `credits`       | 原项目作者与项目作者                         |

维度、题目和专属评语都有稳定 ID。编码存放在倾向的 `code` 中，是可编辑的展示内容；题目引用 `dimensionId` 和 `poleId`，所以修改字母不改变归属。编码支持 1–4 个字母、汉字或数字，同一维度的两侧不能相同。不同维度可以重复使用同一个字母。

## 评分

每题选项取值为 `1…scalePoints`，`scalePoints` 只能为 5 或 7。

```text
中点 = (量表档数 + 1) / 2
题目方向值 = (答案 - 中点) / (中点 - 1)
```

如果题目的「同意时倾向」是维度左侧，题目方向值乘权重后加入该维度；如果是右侧，则取相反数后加入。权重大于 0，且不超过 10，支持小数。

```text
左侧比例 = round(50 + 50 × 该维度方向值加权总和 / 本次该维度题目权重总和)
右侧比例 = 100 - 左侧比例
```

只有本次实际出题参与计算。中立答案不贡献方向值；正向与反向题使用同一规则。所有已选题都答完后才能生成结果，每个维度必须有题目。

相等时显示 `50% / 50%`，并使用该维度的 `tiePoleId` 指定结果编码。平分规则不改变比例，不依赖随机顺序。由于显示时按整数四舍五入，极小的非零差值也可能显示 50/50，此时编码仍按实际未舍入分数确定。

## 出题

- `selection: "all"`：使用全部题目。
- `selection: "balanced"`：每个维度每一侧抽取 `perPole` 道题，必出题占用名额。
- `required: true`：平衡抽题时必须出现。
- `shuffle: true`：随机排列本次所选题目；关闭时保留原题库顺序。

题库不足或必出题超出抽题数量时，编辑器阻止导出并说明具体维度与倾向。刷新会恢复本次抽题顺序和已填答案；修改配置后旧答题记录不会被套用到新版本上。

每题可设置 `labels` 数组覆盖默认的 `settings.scaleLabels`，数组长度必须等于量表档数。这仅修改标签，不修改数字评分。更改量表档数会重置单题标签，避免把旧标签套用到新的档位。

## 编码与评语

主编码按 `role: "main"` 的维度顺序拼接；后缀按 `role: "suffix"` 的顺序统一放在最后，中间用 `-` 分隔。至少需要一个主维度。

专属评语的 `match` 必须精确覆盖当前全部主维度，值是各维度的倾向 ID。后缀不参与专属评语匹配，而是独立展示对应的倾向解释。

```json
{
  "id": "profile-acxm",
  "match": {
    "rhythm": "left",
    "energy": "left",
    "exploration": "left",
    "decision": "left"
  },
  "name": "灵感漫游者",
  "text": "你的专属评语。"
}
```

没有专属匹配时，结果名称和正文由各主维度选中的倾向名称和解释组合。增加主维度、把主维度改成后缀等结构变化后，原有专属组合需要重新指定；界面会列出需要处理的项目。删除维度时会先列出将同时删除的题目和专属评语数量，可撤销恢复。

## 署名、草稿与导出

`credits.original` 与 `credits.project` 分别包含 `name`、`url`、`visible`。两者独立控制；`visible` 为 `false` 时不显示在页面和分享图上。链接只允许完整 HTTP/HTTPS 地址。

浏览器草稿允许保留未填完的内容；导入和正式导出必须通过完整校验。HTML 中只嵌入配置和程序，用户输入作为文字渲染，JSON 中会转义可能结束脚本标签的字符。原文件不会被静默修改。

默认不收集或发送答案，复制、PNG 和文件导出均在浏览器完成。用户主动点击作者链接或源码链接时会打开对应外部网站。托管平台本身的访问日志由该平台管理。

## 界面语言与内容分开保存

界面语言不属于项目配置，不参与配置指纹或评分。浏览器使用独立存储项 `umbti:ui-language`，值为 `auto`、`zh` 或 `en`。自动模式按浏览器的语言偏好顺序匹配中英文及地区变体；没有匹配项时使用英文。

切换语言保留当前页面、编辑分区、答案、草稿、撤销历史和作者原文，导出的配置不变。校验提示使用可翻译的消息模板，用户填写的维度名等参数按原文插入。
